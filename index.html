📥 استيراد من Google Sheets
صدّر البيانات من جوجل شيت كـ Excel أو CSV ثم ارفعها مباشرة إلى Firebase
📋 خطوات الاستيراد
1️⃣
صدّر من Google Sheets
ملف ← تنزيل ← Microsoft Excel أو CSV
2️⃣
اختر نوع البيانات
اضغط على التاب المناسب أدناه
3️⃣
ارفع الملف
اسحب الملف أو اضغط للاختيار
4️⃣
ارفع إلى Firebase
اضغط زر "رفع إلى Firebase"
⚠️ ملاحظة: تأكد أن الصف الأول في ملفك هو صف الترويسة (العناوين) وأن البيانات تبدأ من الصف الثاني. يمكنك تحميل نموذج CSV لكل نوع بيانات للتأكد من التنسيق الصحيح.

لتهيئة Firebase، عدّل ملف js/firebase-config.js وأضف بيانات مشروعك.
// js/firebase-config.js const FIREBASE_CONFIG = { apiKey: "YOUR_API_KEY", authDomain: "YOUR_PROJECT_ID.firebaseapp.com", projectId: "YOUR_PROJECT_ID", storageBucket: "YOUR_PROJECT_ID.appspot.com", messagingSenderId: "YOUR_MESSAGING_SENDER_ID", appId: "YOUR_APP_ID" };

📂 مجموعات Firestore
${['drivers','violations','deductions','licenses','custody','approvals','invoices'].map(c => `
${c}
`).join('')}
يُنشئ النظام هذه المجموعات تلقائياً عند إضافة أول سجل.
🛡 قواعد Firestore الموصى بها
أضف هذه القواعد في Firebase Console → Firestore → Rules
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /{document=**} { allow read, write: if true; // للتطوير فقط } } }
⚠️ للإنتاج: قيّد الوصول بالمصادقة أو عناوين IP محددة.
